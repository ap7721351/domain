Rangkuman Materi 4

Materi Utama

1

Pengertian Program, Aplikasi, dan Sistem Operasi

Program/software adalah sekumpulan instruksi yang saling berkaitan dan dibuat untuk tujuan tertentu. Program memberi tahu komputer tugas apa yang harus dilakukan dan bagaimana melakukannya.

Application (app) adalah program yang dirancang untuk membantu pengguna menjadi lebih produktif atau melakukan tugas pribadi.

Operating system (OS) adalah sekumpulan program yang mengatur dan mengoordinasikan seluruh aktivitas antara hardware komputer/perangkat mobile.

2

Productivity Applications

Productivity applications membantu pengguna bekerja lebih efektif dan efisien dalam aktivitas sehari-hari, baik di tempat kerja, sekolah, maupun rumah.

3

Graphics and Media Software

Multimedia authoring software memungkinkan pengguna menggabungkan teks, grafik, audio, video, dan animasi menjadi aplikasi interaktif.

Website authoring software membantu pengguna membuat halaman web yang dapat berisi grafik, video, audio, animasi, efek khusus, dan konten interaktif.

Media player digunakan untuk melihat gambar/animasi, mendengarkan audio, dan menonton video. Sementara disc burning software digunakan untuk menulis data seperti teks, grafik, audio, dan video ke media disk yang dapat direkam.

4

Security Tools

Software keamanan berfungsi melindungi komputer, perangkat, dan data dari berbagai ancaman.

Personal Firewall

Melindungi komputer dan data dari akses atau penyusupan yang tidak sah.

Antivirus

Melindungi komputer dari virus dengan mendeteksi dan menghapus virus yang terdapat di memori, media penyimpanan, atau file yang masuk.

Spyware

Program yang dipasang tanpa sepengetahuan pengguna dan secara diam-diam mengumpulkan informasi pengguna lalu mengirimkannya ke pihak luar.

Adware

Program yang menampilkan iklan online, misalnya dalam bentuk banner atau pop-up.

Ada pula:

Spyware remover → mendeteksi dan menghapus spyware.

Adware remover → mendeteksi dan menghapus adware.

Anti-spam → membantu menangani spam.

Phishing filters → menyaring ancaman phishing.

Web filtering → menyaring konten web.

Pop-up/pop-under blockers → memblokir jendela iklan tertentu.

5

File, Disk, and System Management Tools

Tools ini digunakan untuk mengelola file, penyimpanan, dan sistem komputer.

File manager → melakukan berbagai fungsi pengelolaan file.

Search tool → mencari file, kontak, acara kalender, aplikasi, atau item lain berdasarkan kriteria tertentu.

Image viewer → menampilkan, menyalin, dan mencetak file gambar.

Uninstaller → menghapus program beserta entri terkait dalam file sistem.

Disk Cleanup : Mencari dan menghapus file-file yang tidak diperlukan.

Disk Defragmenter → Mengatur kembali file dan ruang kosong pada hard disk agar sistem operasi dapat mengakses data lebih cepat dan program dapat berjalan lebih cepat.

Backup & Restore

- Backup tool → membuat salinan file atau seluruh isi media penyimpanan ke lokasi lain.

- Restore tool → mengembalikan file yang telah di-backup ke bentuk/lokasi semula
